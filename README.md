# TACTICAL AIM (전술 에임 트레이너)

발로란트 스타일의 세련되고 미래지향적인 분위기에서 영감을 받아 제작된 전술 2D FPS 에임 트레이너 웹 게임입니다. 순수 React, TypeScript, HTML5 Canvas API 및 Web Audio API를 기반으로 제작되었습니다.

---

## 🎮 주요 기능 및 특징

### 1. 메인 메뉴 & 설정
- **모션 및 전술 다크 UI**: 어두운 네이비 & 차콜 톤, 시안/네온 글로우 포인트, 전술 HUD 스타일
- **연습 시간 선택**: 30초, 60초, 90초
- **표적 크기 조절**: Small (고난도), Normal (표준), Large (워밍업)
- **조준점(크로스헤어) 커스텀**:
  - 컬러: Cyan, Emerald, Crimson, Amber, White
  - 스타일: Tactical (십자+도트+가이드링), Cross (전통 십자선), Dot (단일 도트)
- **사운드 토글**: Web Audio API 기반 오디오 ON/OFF

### 2. 1인칭 FPS 조작 및 2D 전술 사격장
- **Pointer Lock API 시점 조작**: 실제 FPS 게임처럼 마우스를 움직여 가상의 360도 2D 사격장 시점을 좌우 및 상하로 회전
- **화면 중앙 고정 조준점**: 마우스 커서를 완전히 숨기고 화면 정중앙에 고정된 크로스헤어로 표적을 조준
- **사격 피드백 (반동 블룸 & 섬광)**: 좌클릭 격발 시 크로스헤어가 팽창했다가 신속히 수축하는 리코일 블룸 및 전술 발사 섬광/비네트 효과
- **마우스 감도 설정**: 0.2x ~ 3.0x 범위로 사용자 DPI에 맞춘 정밀 감도 조절 지원
- **입체적 사격장 환경**: 원근 격자 바닥, 전술 벽면 패널, 사격선 레일 및 상단 나침반 틱
- **중앙 타격 판정**:
  - **헤드샷 (중심부 타격)**: +200점 (청명한 금속성 핑 사운드, 골드 스파크 파티클, 'HEADSHOT +200' 텍스트)
  - **바디샷 (일반 타격)**: +100점 (타격 사운드, 시안 파티클, '+100' 텍스트)
  - **미스 샷**: 빗나감 카운트 증가, 정확도 감소, 둔탁한 미스음
- **포인터 락 해제 & 일시정지**: ESC 키를 누르면 브라우저 포인터 잠금이 풀리며 즉시 전술 일시정지 모달 호출

### 3. 실시간 HUD & 일시정지 시스템
- **상단 HUD**: 남은 시간 게이지, 현재 점수, 실시간 명중률(%), 적중/빗나감 수, 헤드샷 카운트
- **안전한 일시정지**: 재개(Resume), 재시작(Restart), 실수 방지 확인 다이얼로그가 포함된 메인 메뉴 복귀(Abort to Menu)

### 4. 결과 화면 (MISSION DEBRIEF) & 최고 기록
- 최종 점수, 명중률, 총 적중 수, 빗나간 수, 헤드샷 비율(%) 대시보드
- 이전 최고 점수와 비교 (+/- 증감 표시)
- 신기록 달성 시 축하 뱃지 (`NEW ALL-TIME RECORD ACHIEVED`)
- `localStorage`를 통한 모드별 최고 기록 영구 보존

## 🚀 실행 방법

### 1. 간편 원클릭 실행 (Windows)
프로젝트 폴더 내 `start-game.bat` 파일을 더블 클릭하면 브라우저가 자동으로 실행됩니다.

### 2. 터미널 수동 실행
```bash
npm run dev
```
브라우저에서 `http://127.0.0.1:5173/` 로 접속합니다.

## ⌨️ FPS 조작 방법
- **마우스 이동**: 가상 사격장 시점 회전 (화면 정중앙 조준점으로 타겟 조준)
- **마우스 좌클릭**: 사격 (화면 중앙 기준 명중/헤드샷 판정)
- **화면 클릭**: 마우스 포인터 잠금(Pointer Lock) 활성화
- **ESC 키**: 마우스 포인터 잠금 해제 및 게임 일시정지 (PAUSE)
